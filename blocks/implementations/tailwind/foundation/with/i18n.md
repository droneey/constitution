# Tailwind with i18n

> Layout utilities in a program written for several locales.

## logical-utilities-for-direction → logical-properties-for-direction
No class list writes a physical-side utility — `ml-`, `pr-`, `left-`, `text-left`, `border-l`, `rounded-l` and their kin; the logical ones, such as `ms-`, `pe-`, `start-` and `text-start`, take their place.

|---|---|---|
| a right-to-left locale then mirrors the layout with no second set of classes. | tool/lint | [] |
