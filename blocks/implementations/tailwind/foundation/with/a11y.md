# Tailwind with accessibility

> The accessibility mechanisms in the theme.

## focus-shown-by-focusable-utility · MUST
Focus is shown by the design system's `focusable` utility, and only it removes an outline.
**Why:** one utility draws the same visible ring everywhere, and no component removes focus without it.
**Check:** review
**Tags:** a11y
**Implements:** `focus-always-visible`

## motion-tokens-honour-reduced-motion · SHOULD
The motion tokens collapse under reduced motion, in the theme.
**Why:** every animation reads the tokens, so one rule in the theme stops them all.
**Check:** review
**Tags:** a11y
**Implements:** `reduced-motion-honoured`

## type-tokens-in-rem · SHOULD
Font-size and line-height tokens are in `rem`.
**Why:** the user's text size then scales every text of the interface.
**Check:** review
**Tags:** a11y
**Implements:** `type-sized-in-rem`
