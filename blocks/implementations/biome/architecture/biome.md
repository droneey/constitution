# Biome

> The architecture parts read every file under `src/` outside the edge — adapters, those of a feature and of a composition module among them, `libs/`, `root/`, the entry files, `entrypoints/` and `integrations/` — for the effects reached through a global, and every such file outside the binding units of `app/` for a timer. They also narrow two GritQL rules of the base: the one against `null` to code outside adapters and wire models, and the one against empty names to code outside `src/libs/`. `noConsole` stays on everywhere: the logger adapter and a command's delivery unit write through the process's streams, as the composition root hands them over.
