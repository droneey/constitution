# CSS

> The language of a program's stylesheets, whatever writes the classes: plain stylesheets, scoped stylesheets or a utility library. Cascade layers decide which rule wins, the theme's custom properties carry every visual value, and a component's styles stay its own. A linter holds what it can see in a stylesheet, and the rest is reviewed.
