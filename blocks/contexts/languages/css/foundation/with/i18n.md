# CSS with internationalisation

> How a stylesheet follows the direction of the user's language.

## logical-properties-for-direction · SHOULD
Spacing, borders, sizes and positions use logical properties — `margin-inline`, `padding-block`, `inset-inline-start` — never physical left and right.

|---|---|---|
| a right-to-left or vertical language then flips the layout with no second stylesheet. | review | [ux] |
