# TypeScript with internationalisation

> Governs the locale TypeScript's formatting calls take.

## Formats

### locale-passed-to-every-intl-call → values-formatted-by-the-active-locale · MUST
Every `toLocaleString`, `toLocaleDateString` and `toLocaleTimeString` call and every `Intl` formatter is given the active locale, never nothing or `undefined` in its place.

| Why | Tags |
|---|---|
| without a locale these calls take the runtime's own, the server's or the device's, so a value is shown in a locale the user never chose. | [] |
