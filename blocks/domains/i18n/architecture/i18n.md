# Internationalisation

## locale-reachable-without-props · SHOULD
The current locale is reachable anywhere in the presentation without being passed as a prop.
**Why:** a locale threaded through every component couples all of them to it.
**Check:** review
**Tags:** architecture

## domain-returns-codes-not-text · SHOULD
Domain and application code return codes and values, and the presentation turns them into text; the message library never reaches the domain.
**Why:** the domain stays free of any language, and one code is worded differently per screen and locale.
**Check:** tool — architecture
**Tags:** architecture
**Implements:** `domain-imports-only-itself-and-kernel`
