# Remote service

> Another system the program calls over a transport, run by a vendor the program does not control. This block says how the transport is built and bounded, how its answers are parsed and its failures mapped, how a stream of its events reaches the domain, and how the specs stand in for the vendor with captured answers and keep those answers true.
