# Internationalisation

> Governs how a stylesheet follows the direction of the reader's language.

## Locale

### inline-side-written-logically · SHOULD

A side along the line is written in its logical form, never as left or right. This holds for a margin, padding, border, inset, float, clear or text alignment — `margin-inline-start`, `inset-inline-end`, `text-align: start` — save what keeps its direction in every language, such as a media control.

| Why |
|---|
| a side written as left or right stays put when a right-to-left language reverses the line, so the layout breaks there unless a second stylesheet mirrors it. |
