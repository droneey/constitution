# Code

> Governs the doctype a document opens with.

## General

### document-declares-the-html-doctype · MUST

A document opens with `<!doctype html>`.

| Why | Tags |
|---|---|
| without it the browser lays the page out in quirks mode, by the rules of the browsers of the 1990s, so boxes, tables and line heights differ from what every standard describes. | [] |
