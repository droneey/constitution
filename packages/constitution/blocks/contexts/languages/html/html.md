# HTML

> HTML, the markup a browser builds its document from: its elements and attributes carry a page's structure, its metadata and the semantics assistive technology reads, whether a file holds them or a framework renders them; a lightweight markup language's own syntax, which a renderer turns into HTML, is none of it.
