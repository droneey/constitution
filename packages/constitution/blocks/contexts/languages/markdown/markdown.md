# Markdown

> **Markdown**, the format of a repository's readmes, agent files and documents, read as plain text as often as it is rendered by a forge, an editor or a site.

**CommonMark** specifies it, and GitHub Flavored Markdown adds the tables, task lists, strikethrough and autolinks most forges render.
