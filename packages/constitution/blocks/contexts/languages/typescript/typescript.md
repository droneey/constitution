# TypeScript

> Programs written in **TypeScript**, and the JavaScript beside them: their source files and imports, their types, failures and effects.

A package others import opens at **`index.ts`**, and a program starts at **`main.ts`**; an ambient declaration lives in a **`.d.ts`**{#ambient-declaration} file, and a comment a tool reads is **JSDoc**.

Most rules give a rule of core, or of a block this one meets, the form it takes in TypeScript.
