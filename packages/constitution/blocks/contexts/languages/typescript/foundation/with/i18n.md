# Internationalisation

> Governs the locale TypeScript's formatting calls take.

## Formats

### locale-passed-to-every-intl-call → values-formatted-by-the-active-locale · MUST

Every `toLocaleString`, `toLocaleDateString` and `toLocaleTimeString` call and every `Intl` formatter that formats text for a person is given the active locale, never nothing or `undefined` in its place.

| Why |
|---|
| without a locale these calls take the runtime's own, the server's or the device's, so a value is shown in a locale the user never chose. |

### text-sorted-by-a-collator-of-the-active-locale → text-sorted-by-the-locale · SHOULD

Text a person reads is sorted and compared by `Intl.Collator` or `localeCompare` given the active locale, never by the default sort, which orders by code unit.

| Why |
|---|
| the default sort puts `Z` before `a` and every accented letter after `z`, and a collator without a locale takes the runtime's. |
