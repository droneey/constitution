# Browser

> A program that runs in a browser tab, on a device its user controls.

The program is downloaded as a bundle with its configuration served beside it, lives in a document the browser can hide, freeze, restore and close at any moment, and keeps in the tab's storage only what the browser lets it keep; its user can read everything it ships.
