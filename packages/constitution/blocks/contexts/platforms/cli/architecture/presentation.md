# Presentation

> Governs the presentation of a command-line program: where a command sits.

## Homes

### command-is-its-operations-binding-unit → delivery-unit-beside-what-it-serves · MUST

A command is the binding unit of the operation it runs. It is one file carrying the role suffix **`.cli`**{#command-binding} in the language's spelling, and no folder of the tree gathers the commands.

| Why |
|---|
| a command kept apart from its operation is changed in a second place whenever the operation changes, and a folder that gathers commands names the platform the whole program already is. |
