# User interface

> Screens a person sees and uses, built from declarative components that take their inputs as props: how they are composed and where their state lives, how components are sourced, built and named, the words they show, how forms take input, what every person must be able to do whatever their sight, hearing, movement or attention, and how an interface is proven.

A prop is an input a component takes — a parameter, where the framework calls it so. The interface's look, when the product owns it, is the design system's.
