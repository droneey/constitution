# Deployment

> A program that reads settings where it runs: the one artefact it runs as in every deployment environment, which holds none of the settings that differ between them, how they enter it, are checked and change while it runs, what its code branches on in each deployment environment, how its feature flags end, and, on the architecture axis, the one unit that reads its configuration inputs.
