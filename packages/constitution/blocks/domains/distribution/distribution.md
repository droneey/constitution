# Distribution

> A unit others install from a package registry: a package whose code they import or whose configuration they extend, or a program such as a command-line tool its users install.

The block covers what the unit contains, its manifest, how it is published and released, the runtimes it supports and its versions, on which everyone who installs it relies.
