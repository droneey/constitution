# AI

> A program that sends prompts to a language model and acts on what it returns: how a model is named and pinned, how a prompt keeps the program's instructions apart from text others wrote, how an output is parsed and when it is complete, which model tools a model may call and which calls wait for a person, what a call, a run and a caller may spend, how documents are retrieved for a model and cited, what a model run remembers, how its behaviour is measured by evals kept apart from the specs, and where a model is reached.
