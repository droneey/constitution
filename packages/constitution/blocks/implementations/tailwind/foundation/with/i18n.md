# Internationalisation

> Governs layout utilities in a program written for several locales.

## General

### logical-utilities-for-direction → inline-side-written-logically · SHOULD

A class list writes logical sides, never physical ones. The physical-side utilities — `ml-`, `pr-`, `left-`, `text-left`, `border-l`, `rounded-l` and their kin — give way to the logical ones, such as `ms-`, `pe-`, `start-` and `text-start`.

| Why |
|---|
| a physical side stays where it is in a right-to-left locale, so the layout is mirrored wrong unless a second set of classes undoes it. |
