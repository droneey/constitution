# Internationalisation

> Governs layout utilities in a program written for several locales.

## General

### logical-utilities-for-direction → inline-side-written-logically · SHOULD

No class list writes a physical-side utility — `ml-`, `pr-`, `left-`, `text-left`, `border-l`, `rounded-l` and their kin; the logical ones, such as `ms-`, `pe-`, `start-` and `text-start`, take their place.

| Why | Tags |
|---|---|
| a right-to-left locale then mirrors the layout with no second set of classes. | [] |
