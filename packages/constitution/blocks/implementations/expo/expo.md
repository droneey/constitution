# Expo

> React Native through **Expo**.

Its routes are **Expo Router**'s, its settings **`app.config.ts`**, and its builds **EAS**'s, set in **`eas.json`**. The block is written thin, like React Native, which it requires: the rest waits for the first mobile project.
