# Formatter

> Governs Biome's formatter: the files it formats and the style it writes.

## General

### biome-formats-every-file-it-reads → one-formatter-per-language · MUST

Biome formats every file of the languages it covers — code, stylesheets, JSON and YAML — and of no other, with single quotes in code, stylesheets and YAML.

| Why |
|---|
| one formatter for the languages Biome reads ends every argument about their layout. |
